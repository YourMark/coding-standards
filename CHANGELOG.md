# Changelog

## 1.0.0

- Added the `YourMark` PHPCS standard: WordPress Coding Standards with required short arrays,
  required non-Yoda conditions, PSR-4 filenames, slash-separated hook names and relaxed rules for `tests/`.
- Added `phpstan/wordpress.neon`: level 7 with WordPress stubs and `treatPhpDocTypesAsCertain: false`.
